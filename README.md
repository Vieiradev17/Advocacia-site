# ⚖️ Landing Page para Escritório de Advocacia

> Website institucional e responsivo voltado para conversão de clientes e apresentação dos serviços jurídicos do escritório.

💻 **Acesse a aplicação online:** [https://advocacia-app.netlify.app](https://advocacia-app.netlify.app)

---

## 🚀 Sobre o Projeto

Uma landing page moderna desenvolvida para proporcionar uma experiência de navegação fluida, elegante e profissional para potenciais clientes de um escritório de advocacia. O foco do projeto foi a criação de uma interface limpa, acessível e otimizada para dispositivos móveis, garantindo um canal direto de contato com o cliente (CTA via WhatsApp e formulário).

---

## ✨ Principais Funcionalidades

- **Design Institucional e Sofisticado:** Paleta de cores e tipografia pensadas para transmitir credibilidade e autoridade.
- **Totalmente Responsivo:** Adaptação perfeita para smartphones, tablets e desktops.
- **Seção de Áreas de Atuação:** Exibição clara e organizada dos serviços oferecidos.
- **Chamadas para Ação (CTAs):** Botões estratégicos direcionados para contato direto via WhatsApp.
- **Formulário de Contato:** Interface amigável para envio de dúvidas e agendamento de consultas.

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** React.js / JavaScript (ES6+)
- **Estilização:** CSS3 / Tailwind CSS (ou Styled Components)
- **Componentização:** Design modular e reutilizável
- **Hospedagem:** Netlify

---

## 💡 Desafios e Aprendizados Técnicos

- **Hierarquia Visual e UX:** Estruturação de conteúdo focada na jornada do usuário para aumentar a taxa de conversão.
- **Otimização de Performance:** Carregamento rápido de imagens e assets para garantir uma excelente nota no Lighthouse.
- **Mobile First:** Desenvolvimento com foco em usabilidade para dispositivos móveis.
